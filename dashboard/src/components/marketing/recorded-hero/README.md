# Recorded hero — V1

The real Companion and Claude Code mock are driven by the video's current time.
This scene shows the search fix, tests and production deployment. Its source
camera/microphone take is versioned in `tools/demo-recorder/takes/hero-v1`.

The microphone's six user-marked noise intervals are replaced with the selected
room tone before mixing Lux. Transcript corrections restore missing prefixes
without changing arrival times. Video, audio, replies and pauses keep their
original timeline. Activity cues will be authored separately.

See `tools/demo-recorder/takes/README.md` for source files, cleanup details,
rebuild commands and an uncleaned A/B export. Camera framing stays in Vue,
not in the video. The camera sits bottom-left and the scene sound control top-left.
